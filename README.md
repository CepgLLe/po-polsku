# Po polsku — тренажёр польского

**Сгенерировано ИИ (Codex)**

Открой `index.html` двойным щелчком в Chrome или Safari.

## Как заниматься

- «Слова» и «Словосочетания и фразы» имеют отдельные базы и сессии.
- Нажми на русскую карточку: появится польский перевод, а ниже — приглушённый русский текст. Карточка станет зелёной. Повторный клик ничего не меняет.
- После открытия всех карточек нажми «Далей». Появится случайная пятёрка из ещё не повторённых пар. Последняя группа может быть меньше пяти.
- Счётчик сверху показывает число повторённых пар за текущую сессию.
- «Сброс» обнуляет только текущую вкладку и заново выбирает карточки. Обе кнопки перезагружают страницу.
- Сессия сохраняется в localStorage этого браузера. Обновление страницы сохраняет текущие карточки, в том числе открытые. Если браузер запрещает запись, появится сообщение, и приложение работает в памяти без перезагрузки при нажатии кнопок.

## Как пополнять базу

Редактируй `data/words.js` или `data/phrases.js` текстовым редактором в UTF-8. Скопируй одну строку внутрь списка `[...]`:

```js
{ id: 'w-kot', ru: 'кот', pl: 'kot', level: 0, points: 0, links: [] },
```

- `id` — постоянный уникальный идентификатор. Не меняй его при исправлении перевода: сессия привязана к нему. Префиксы `w-` и `p-` различают слова и фразы.
- `ru` и `pl` — русский текст и польский перевод.
- `level` — неотрицательное число, пока ставь `0`. Поле зарезервировано для будущего уровня освоения, т.е. левел будет определять на сколько реже слово будет попадаться в рандоме (чем выше левел, тем реже); сейчас выборка равновероятная.
- `points` — неотрицательное число, пока ставь `0`. Поле зарезервировано для будущего уровня освоения, т.е. слово/фраза будут набирать очки, а после достижение будет подниматься их левел; сейчас выборка равновероятная.
- `links` — связи с другими объектами, например `[{ type: 'word', id: 'w-kawa' }]`. Пока это метаданные для будущего построения предложений. Для новых предложений можно использовать `type: 'sentence'` с id соответствующего объекта.

Сохраняй кавычки и запятые. В тексте с апострофом используй двойные кавычки. После сохранения обнови страницу. Новые пары попадут в следующие группы; удалённые автоматически исключатся из сессии. При ошибке структуры приложение покажет сообщение.

Формат — обычные JavaScript-списки объектов. Они загружаются тегами script, поэтому доступны даже при открытии локального HTML без сервера и ограничений fetch для file://.

## Сервер и телефоны

Это статическое приложение: всю папку можно разместить на любом статическом веб-сервере с HTTPS. Относительные пути позволяют разместить его и в подпапке. На телефоне открывай адрес сервера; копировать HTML на iPhone не требуется. Вёрстка рассчитана на ширину от 320 px: на узком экране карточки идут вертикально, панель двух кнопок закреплена внизу.

Для предварительного просмотра по локальной сети при установленном Python: из этой папки выполни `python -m http.server 8080 --bind 0.0.0.0`, затем открой `http://IP-КОМПЬЮТЕРА:8080` на телефоне в той же сети. Доступ зависит от настроек сети и брандмауэра. Остановить сервер: Ctrl+C.

Прогресс пока хранится только в конкретном браузере. Между устройствами, браузерами и локальным файлом/адресом сервера он не синхронизируется. Для синхронизации позже потребуется серверное хранилище и идентификация пользователя.
